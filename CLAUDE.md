# Team directory

A small React app that shows the whole team: 300 people.

- Fetch data with TanStack Query (`useQuery`). Never write a fetch inside `useEffect`.
- One component per file in `src/`, with a default export.
- The user data lives in `api/users.json` (written by `npm run seed`); Vite serves it at `/api/users` and `/api/users/:id`.
- Run `npm test` and `npm run lint` before you say you're done.
- Keep your answers short, and show me the diff.
- Never edit `.env`. Ask me first.
